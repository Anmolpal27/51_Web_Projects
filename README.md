## 🌟 About The Project

This repository contains a curated collection of web development projects ranging from beginner to intermediate level.

The goal of this repository is to:

- Help beginners practice web development
- Encourage open-source contributions
- Build real-world frontend projects
- Improve problem-solving and development skills
- Provide hands-on learning experience

## 🚀 Getting Started

### Fork The Repository

Click the **Fork** button at the top-right corner of this repository.

### Clone The Repository

```bash
git clone https://github.com/jaikaran109/51_Web_Projects.git
```

### Navigate To The Repository

```bash
cd 51_Web_Projects
```

### Open Any Project

Choose any project folder and open the `index.html` file in your browser.

## 🤝 Contributing

Contributions are welcome and appreciated.

### How To Contribute

1. Fork the repository
2. Clone your fork
3. Create a new branch (`git checkout -b feature/your-feature-name`)
4. Make your changes
5. Commit your changes (`git commit -m "Fix: ..."` or `git commit -m "Add: ..."`)
6. Push your branch (`git push origin feature/your-feature-name`)
7. Open a Pull Request

Please read [CONTRIBUTING.md](CONTRIBUTING.md) before contributing.

> 📌 **PR format:** Add a clear title (`Fix:` / `Add:` / `Docs:` / `UI:`), a short description, and **screenshots** for UI/UX changes.

## 🗂️ Scripts

The `scripts/` directory contains automation scripts for managing GitHub issues:

- `create-github-issues.sh` - Bulk create per-project issues
- `create-github-issues-part2.sh` - Additional batch of issues
- `close-batch1.sh` - Close unused/generic issues
- `tmp-check.sh` - Temporary check script

> ⚠️ These scripts are for repository maintainers and use GitHub CLI (`gh`).
